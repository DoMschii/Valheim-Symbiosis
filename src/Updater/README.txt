Valheim Symbiosis Updater
=========================
Der Updater prueft beim Valheim-Start GitHub Releases.
Eine neue Stable-Version wird im Hintergrund heruntergeladen und nach dem Beenden von Valheim installiert.
Die GitHub-Zuordnung wird ueber Valheim_Symbiosis_Update.json neben der DLL gesteuert.
Ohne diese Datei oder mit enabled=false bleibt der Updater inaktiv.
