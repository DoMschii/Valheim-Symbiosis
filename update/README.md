# Update channels

The preloader updater reads JSON manifests from this directory.

## RC1 policy

- `stable.json` is intentionally **not** committed for the RC.
- `beta.json` is generated by `ReleaseTools/Publish-RC1.ps1` only after the GitHub
  release assets exist and their SHA-256 has been calculated.
- Normal installations remain on the currently installed version until a real
  stable release is promoted.

A manifest looks like:

```json
{
  "version": "0.6.0",
  "channel": "beta",
  "package_url": "https://github.com/OWNER/REPO/releases/download/v0.6.0-rc1/Valheim_Symbiosis_PreStart_Update_v0.6.0-rc1.zip",
  "sha256": "..."
}
```
