Valheim_Workers_Mount v0.1.48 - Smooth Flight / Camera Jitter Fix

- Fixed a real ego-camera scaling bug: animator wingbeat values were already metres but were multiplied by 10.
  This turned 6-14 mm motion into 6-14 cm camera jumps.
- Added low-pass filtering to the wingbeat camera offset.
- Enabled Rigidbody interpolation while symbiosis is active and restores the previous setting on exit.
- Smooths manual flight acceleration/deceleration and body rotation.
- Uses Rigidbody.MoveRotation when available instead of fighting physics interpolation with direct transform writes.
- Idle hover no longer rewrites Transform + Rigidbody every render frame when already stable.
- Ego root-position follow is calmer while mouse aim remains immediate.
- No changes to existing key layout, attack logic, AI lock, health forwarding, persistence or DrakeForm binding.
