# One-click installer

Release asset: $oneClickName

End users:

1. Extract the ZIP.
2. Double-click INSTALLIEREN.bat.
3. Start Valheim through Thunderstore/r2modman using Play Modded.

The installer deploys the complete Valheim Symbiosis suite and preloader updater
to detected profiles that already contain BepInEx 5 and Jotunn.
