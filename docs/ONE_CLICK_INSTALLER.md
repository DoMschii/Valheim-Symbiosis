# One-click installer

Release asset: $oneClickName

End users:

1. Extract the ZIP.
2. Double-click INSTALLIEREN.bat.
3. Start Valheim through Thunderstore/r2modman using Play Modded.

The installer includes the official BepInExPack Valheim and Jotunn archives.
It installs into existing Thunderstore/r2modman profiles when available, or
performs a complete direct Valheim installation when no profile exists.
